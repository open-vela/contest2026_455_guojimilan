# 智能垃圾桶翻盖控制技能（trash-lid-control）

## 一、触发场景

| 用户意图示例 | 动作 |
| ------------ | ---- |
| "开盖 / 打开垃圾桶 / 我要扔垃圾" | 开盖（90°） |
| "合盖 / 关上 / 收起来" | 合盖（0°） |
| "垃圾桶开着吗？" | 查询并播报当前状态 |

## 二、设备与通道

- **执行端**：GD32F470V-START，运行 openvela（NuttX）固件
- **通道**：串口 `/dev/ttyS0`（USART0，57600-8N1，PA9=TX / PA10=RX）
- **命令帧**：`L,<deg>\n`
  - `deg >= 45` → 开盖（90°），如 `L,90`
  - `deg < 45` → 合盖（0°），如 `L,0`
- **回执帧**（设备 → Agent，500ms 级）：
  - `GD32:lid open (90 deg)` / `GD32:lid close (0 deg)`（指令执行）
  - `GD32:lid auto-close (60s timeout)`（超时自动合盖事件）
- K230 视觉坐标帧（`B,x,y\n`）与控制帧共用串口，以帧头字符区分（B/L）。

## 三、执行方法

1. 解析用户意图得到目标角度：开盖 = 90，合盖 = 0。
2. 通过 shell 工具发送串口命令：
   ```bash
   echo "L,90" > /dev/ttyS0    # 开盖
   echo "L,0"  > /dev/ttyS0    # 合盖
   ```
3. 读取回执帧确认执行结果，向用户播报（如"盖子已打开，请投放垃圾"）。
4. 若回执为 `auto-close` 事件，主动告知用户："盖子已超过 60 秒未关闭，我已自动合上，防止异味扩散。"

## 四、主动 + 执行场景（阈值主动）

**开盖超时自动合盖**：
- 检测条件：翻盖处于打开状态持续 60 秒，且期间无新的开/合指令；
- 主动动作：设备固件自动执行合盖（0°），OLED 同步刷新，并向串口上报
  `GD32:lid auto-close (60s timeout)`；
- Agent 侧：收到该事件后主动向用户说明，不需要用户先开口询问。

该场景同时具备"用户主动（语音/文字指令开合盖）"与"设备主动（超时保护）"两类交互，
是本技能区别于普通遥控开关的核心。

## 五、备注

- 电机为 DCC-101 闭环步进驱动（16384 步/圈），到位精度由驱动器闭环保证，无需轮询位置。
- 按键（PB12）本地控制与 Agent 指令控制共享同一状态机，动作互斥且状态一致。
